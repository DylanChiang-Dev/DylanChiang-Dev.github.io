InkRelay（墨流）是我設計的開源內容製作 Skill，將作者的材料、文風與發布目的轉成 Agent 可以接續執行的步驟。它不是一鍵產文或固定渲染器，而是讓核心文字先被確認，再按需求製作封面、圖卡或文字影片的協作流程。

<!--more-->

## 我做了哪些工作

- **建立長短文兩條流程**：長文先整理來源與論證骨架，再分節起稿及局部修訂；短文先完成一份核心稿，不因新增平台用途而重新起稿。
- **設計作者確認點**：區分未確認草稿、已核准核心稿與派生素材，避免 Agent 把試作當成批准，或擅自發布內容。
- **整理封面生成方法**：把作者氣質、文章論點、單一視覺概念及既有樣稿轉成提示詞，讓封面服務內容，而不是只按題材堆道具。
- **處理平台差異**：規劃繁體 FB／X 橫圖、公眾號橫圖與可裁方區，以及短文 3:4 圖卡、9:16 文字影片；不強迫每篇同時交付所有形式。
- **規範工具與素材邊界**：依現有工具及當篇授權編排製作，沒有工具時說明缺項；不硬編碼個人品牌、模型、字型、音樂或 API 憑證。
- **建立迭代與走查記錄**：分開檢查內容正確性與實際呈現，保存問題、局部修正及重查結果；流程走查不冒稱獨立模型效果評測。

## 實作範圍與取捨

公開版本提供 Skill、製作規格及情境走查紀錄，不捆綁固定渲染器。實際圖片與影片依使用者環境中可用、已授權的工具製作；不自動付費、投稿、發布或排程。這個專案展示的是工作流設計、作者聲音校準與多格式工具編排，不以「全自動生成」取代創作判斷。
