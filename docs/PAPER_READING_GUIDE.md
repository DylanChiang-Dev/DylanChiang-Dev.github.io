# 論文閱讀筆記撰寫指南 (Paper Reading Guide)

這份指南旨在規範網站上的「論文閱讀筆記」寫作風格與結構，確保內容既有學術深度，又具備個人洞見。

## 1. 核心目的 (The Why)

我們為什麼要寫這些筆記？這不僅僅是為了摘要（Summary），而是為了**知識綜合（Knowledge Synthesis）**。

*   **內化知識**：通過重寫和重構，將被動閱讀轉化為主動理解。
*   **建立連結**：將新論文與現有的知識體系（如心理學、AI、經濟學）進行連結。
*   **批判性思考**：不盲目接受結論，而是評估其方法的嚴謹性和結論的適用範圍。
*   **長期記憶**：未來的自己是這些筆記最重要的讀者。

## 2. 結構與模板 (Structure & Template)

一篇標準的論文閱讀筆記應包含以下章節。請直接複製以下 Markdown 模板開始寫作。

### 📋 Copy-Paste Template

```markdown
---
title: "論文中文標題 (英文標題)"
date: 202X-XX-XX
authors:
  - admin
tags:
  - 論文閱讀
  - 領域標籤 (e.g., 心理學)
  - 具體標籤 (e.g., 辣椒素)
summary: "一句話總結論文的核心發現與你的核心洞見。"
draft: false
featured: false
---

> **原文資訊**
> *   **標題**: [Original English Title](URL to Paper)
> *   **作者**: Author A, Author B, et al.
> *   **期刊/會議**: Journal Name / Conference Year
> *   **日期**: YYYY-MM

## 核心發現 (Key Takeaways)

*   **一句話總結**：用最簡單的話說清楚這篇論文發現了什麼。
*   **主要結論 1**：詳細說明結論 1。
*   **主要結論 2**：詳細說明結論 2。

## 研究背景與問題 (Background & Motivation)

*   這篇論文試圖解決什麼問題？
*   過去的研究有什麼不足（Research Gap）？
*   為什麼這個問題很重要？

## 研究方法 (Methods)

*   **受試者/數據集**：使用了什麼數據？（e.g., N=100, 雙盲實驗）
*   **實驗設計**：如何控制變量？使用了什麼模型？
*   **關鍵變量**：自變量（IV）和因變量（DV）分別是什麼？

## 詳細結果 (Results)

*   在此處列出支持核心發現的具體數據或圖表解釋。
*   如果有圖表，請簡要描述圖表的含義。

## 重要性與影響 (Significance)

*   這項研究對該領域有什麼貢獻？
*   實際應用價值是什麼？

## 💡 我的理解與思考 (My Understanding)

*(這是最重要的部分！)*

*   **批判性思考**：這篇論文有什麼限制？方法上有沒有漏洞？
*   **跨領域連結**：這讓我聯想到了什麼？（例如：這個心理學現象是否解釋了某些 AI 行為？）
*   **未來方向**：如果是我，下一步會做什麼研究？
*   **生活應用**：這對我的日常生活或工作有什麼啟發？
```

## 3. 寫作風格與語氣 (Style & Persona)

*   **Persona**: Dylan Chiang (學術研究者/工程師)。
*   **語言**: **繁體中文 (Traditional Chinese)**。
*   **語氣**:
    *   **學術但不枯燥**：使用精確的術語，但用流暢的邏輯串聯。
    *   **第一人稱**：在「我的理解」部分，大膽使用「我認為」、「這讓我聯想到」。
    *   **對話感**：像是在跟一位聰明的同行分享剛讀完的好文章。
*   **格式**:
    *   多用 **粗體** 強調重點。
    *   多用列點（Bullet points）提高可讀性。
    *   段落不宜過長。

## 4. 工具與資源 (Tools)

*   **論文來源**:
    *   Google Scholar (學術搜尋)
    *   arXiv (AI/CS 預印本)
    *   Nature/Science/Cell (頂級期刊)
    *   PubMed (生醫領域)
*   **DOI 解析**: 使用 DOI (Digital Object Identifier) 確保引用的永久性。
*   **AI 輔助**: 可以使用 AI (如 Claude/ChatGPT) 幫助快速摘要長文，但**必須人工核實**核心數據，且「我的理解」必須原創。
